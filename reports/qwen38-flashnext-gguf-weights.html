Flash-Next GGUF weights: the Swift 1.5 IQ4_XS stays the best pack

Seven GGUF packs of the same model on the same Splash release: Swift 1.5 fine-tunes by UkisAI, Unsloth UD quants, and GSQ-RCO quants by ISTA-DASLab. Speed, a six-suite battery and a tool-call probe for each, and a second battery pass for two of them.

The Swift 1.5 IQ4_XS pack stays the best GGUF for Splash. No other pack meets the candidate rule: a median token count or median time at least 10% below the Swift pack on both GPQA and LiveCodeBench, quality within the per-suite margin, and tool calls no more than one session below. Every other pack spends 1.09–7.75× the Swift median tokens on those two suites.

Method and limits

  • One rig: Mac Studio, Apple M4 Max, 128 GB. Every pack ran on Splash 1.5.0 with a 262,144-token context and the default flags. Splash 1.6.0 did not pass the switch rule of the Splash 1.6 campaign.
  • Every request sends reasoning_effort: xhigh, temperature 1.0, top_p 0.95, top_k 20, min_p 0. Questions run one at a time.
  • Battery: HumanEval 164, GPQA-Diamond 50, LiveCodeBench v6 50, Tool calling · jdhodges 40, Tool calling · Veerman 12, Instruction following 20, 336 in all. GPQA-Diamond and LiveCodeBench are 50-question samples (seed 42).
  • One pass per pack, except the Swift 1.5 IQ4_XS and the Unsloth UD-IQ4_XS V3.1 packs, which ran twice. The differences between the other packs are not a verdict.
  • Tool calls: the probe runs 20 sessions per profile. Each session is 4 tool-call turns and a final check. The score counts the sessions where all 5 are correct. fp0 sends frequency_penalty 0; fp1 sends 1, as the Crush harness does. One run per pack. The ISTA Q2_0 pack ran 97 of 100 turns in fp0.
  • Turn time is the end-to-end p50 of the speed test: 13 requests at 262,144 tokens over 3 repetitions. It includes thinking. Decode p50 and the RAM peak come from the same requests. Swap did not grow on any pack.
  • Pack size is the Hugging Face size of the variant.
  • ThinkingCap (bottlecapai/ThinkingCap-Qwen3.8-Flash-Next-GGUF@2a053f7) failed at load on Splash 1.5.0 and 1.6.0: this GGUF stores tensors Splash cannot load: hc_attn_inject.weight IQ4_XS (48 tensors), hc_ffn_inject.weight IQ4_XS (48 tensors).
  • Agent quality (for example Terminal-Bench) is not measured.

Download and serve the Swift 1.5 IQ4_XS pack at the revision this page measured. The repository is gated on Hugging Face.

hf download ukisai/Swift-1.5-Qwen3.8-Flash-Next-GGUF --revision 0142554c963a8653912c0c8283f05f13f63653f3 --include "IQ4_XS/*"
splash serve --model ukisai/Swift-1.5-Qwen3.8-Flash-Next-GGUF:IQ4_XS --revision 0142554c963a8653912c0c8283f05f13f63653f3 --host 0.0.0.0 --port 8585 --max-context 262144 --idle-release off --no-webui
