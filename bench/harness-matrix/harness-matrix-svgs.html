Method: prompts run through the named harness against the named model; verdicts distilled to bench/harness-matrix/results/, with raw artifacts under logs/<harness>/<model>/. The page needs the full repo served.

Thinking level = the reasoning effort the harness sent on the wire (each harness uses a different field; see bench/qwen3.8-harness-eval/plan.md). Flash-next's runs used xhigh (recorded in its verdict card); the other arms never recorded a per-run effort and show n/r in the model-badge tooltips. Effort is the strongest lever on token count.

Control arms (opus-4-8, opus-5) are Anthropic-hosted. An additional Claude Code series uses claude-fable-5-1. It appears only in the artifact gallery because it has no pair verdict. Harness, model, provider, and hosting are confounded, so the page compares observed pairs rather than attributing differences to one factor.
