Steno, five ways.

A landing page for a second‑brain notes app, pitched five directions. Each has a small switcher in the corner.

  1. 1Highlightbone paper, highlighter yellow, animated swipesview
  2. 2Graphviolet dark, five‑hue tag system, living note graphview
  3. 3Margincritical edition, blue‑pencil annotations, footnotesview
  4. 4Desklibrary green, taped index cards, ruled paperview
  5. 5Capturemonochrome utility, a working capture barview
Serving from python3 -m http.server or any static host.
