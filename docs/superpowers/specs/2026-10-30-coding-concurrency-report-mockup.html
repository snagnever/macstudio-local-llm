3. Worst case: both sessions read a big prompt at the same time

When does it happen, and how bad is it?

A session start (20K new tokens), a large file or grep result (5–30K), a compaction, a resumed conversation. Splash reads one prompt at a time, so the other session waits for the read. mlx-serve lets a short call wait minutes behind a long read.

5. Long sessions: two at 256K

A cold 256K read takes ~12 min on both servers, and on Splash the other session waits for it. After the read, both sessions turn in ~12 s on Splash.
