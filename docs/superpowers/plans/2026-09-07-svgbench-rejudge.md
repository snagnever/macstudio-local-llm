# SVGBench Re-Judge Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Re-judge all 89 harness-matrix SVG artifacts under one judge so the scoreboard compares models on a single scale.

**Architecture:** The existing `scripts/svgbench/svgbench_eval.py` driver already does manifest → render → score. Only the judging step changes: every verdict file is rewritten by hand from the headless-Chrome render, with one identical `judge` block, replacing the current mix of four judges. `scores.json` is regenerated, never hand-edited. Judging batches by question, because one question's requirement list is shared by all its artifacts and a reviewer can gate a whole question at once.

**Tech Stack:** Python 3 stdlib only (the driver has no dependencies), headless Chrome for rendering, `sips` for crops.

**Spec:** `docs/superpowers/specs/2026-09-07-agent-comparison-site-design.md`, section 8.

## Global Constraints

- **All paths are relative to `bench/harness-matrix/`** unless stated otherwise. Run the driver from there.
- **One judge for every verdict written in this pass.** Each verdict file carries exactly:
  `"judge": {"kind": "claude-vision", "model": "claude-opus-5", "date": "2026-09-07", "method": "viewed the Chrome render plus 2x crops of detail regions; strict per-requirement pass/fail"}`
  The `method` string is byte-identical across all 84 files, so the common threshold is auditable.
- **Judge the PNG render, never the SVG source.** A feature present in the source but absent from the render does not count.
- **Strict per-requirement.** A requirement with several conditions fails if any one fails. A grey-dolphin requirement fails for a blue dolphin; a "two small clouds" requirement fails for four. The failing condition goes in `note`.
- **Requirement `text` is copied verbatim** from `scripts/svgbench/questions.json`, in order, all of them. A mismatch makes `score` raise `StaleVerdict`.
- **Never edit `results/svgbench/scores.json` by hand.** It is generated by the `score` subcommand.
- **Never move a stray SVG** into a model directory to make it scorable.
- **A variant whose render is visually identical to its base variant** copies the base verdicts and adds `"note": "render is visually identical to the base variant; same verdicts"` inside the `judge` object.
- **`claude-opus-5` is a contestant** with 21 artifacts. That is accepted and disclosed, not hidden. Task 13 puts the disclosure on the page.
- **Commit after every task.** Verdict files are the irreplaceable output of this pass.
