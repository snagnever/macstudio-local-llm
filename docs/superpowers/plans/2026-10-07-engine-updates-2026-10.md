**Goal:** Medir no M4 Max se MTPLX 2.12.2, oMLX 0.7.0, mlx-dspark 0.20.3 e ds4 upstream batem a referência no mlx-serve 26.10.1, com um veredito para o Flash-Next e um ranking para o Qwen3.8-27B.

**Architecture:** A campanha nova `bench/engine-updates-2026-10/` reaproveita o driver `run-candidate.sh` da campanha de 2026-09 (saída redirecionada por `FLASHNEXT_RESULTS_DIR`/`FLASHNEXT_LOGS_DIR`) e os launchers por runtime de `bench/qwen3.8-prefix-cache/scripts/`. **Tech Stack:** bash, Python 3 stdlib, `pytest` via `uv run --no-project --with pytest`, `uv venv`/`uv pip`, `cache_probe.py`, mlx-serve, MTPLX, oMLX, mlx-dspark, ds4.

import os

    env = {k: v for k, v in os.environ.items()
           if not k.startswith(("QWEN38_", "FLASHNEXT_", "MLX_SERVE_", "MTPLX_", "ENGINE_"))}
    env.update(extra or {})

    out = subprocess.run(["bash", str(BAND), part, ctx], capture_output=True, text=True,
                         env=_env({"ENGINE_BAND_DRY": "1", **(extra or {})}), check=True)

# bench/engine-updates-2026-10/scripts/run-band.sh
#!/usr/bin/env bash
# Uma banda (32K ou 128K) de uma parte (fn = Flash-Next, 27b), 3 reps. A ordem a 128K é a
# inversa da de 32K. O d1 só entra com ENGINE_D1=1 (passou o gate do smoke).

case "$PART" in
  fn) ARMS=(n2 m1 o1); [[ -n "${ENGINE_D1:-}" ]] && ARMS+=(d1); TAG=fn ;;
  27b) ARMS=(r27 m27 o27 s27); TAG=d27 ;;
  *) echo "parte fora do plano: $PART" >&2; exit 64 ;;
esac
case "$CTX" in
  32768) ORDER=("${ARMS[@]}") ;;
  131072) ORDER=(); for ((i=${#ARMS[@]}-1; i>=0; i--)); do ORDER+=("${ARMS[$i]}"); done ;;
  *) echo "banda fora do plano: $CTX" >&2; exit 64 ;;
esac
for arm in "${ORDER[@]}"; do
  if [[ -n "${ENGINE_BAND_DRY:-}" ]]; then
    echo "bash run-arm.sh $arm $CTX --repeat 3 --tag $TAG"; continue
  fi
  rc=0; bash "$HERE/scripts/run-arm.sh" "$arm" "$CTX" --repeat 3 --tag "$TAG" || rc=$?
  echo "exit[$arm@$CTX]=$rc"
  sleep 120
done
